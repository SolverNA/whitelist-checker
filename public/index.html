История проверок

Каждый ресурс запрашивается из вашего браузера (fetch, no-cors) с таймаутом. «OK» значит, что DNS, TCP и TLS прошли и сервер ответил. Это не ICMP-пинг, время включает DNS и TLS. DoH проверяется настоящим DNS-запросом (RFC 8484). DoT (порт 853) из браузера проверить нельзя. Для IP по HTTPS возможен ложный сбой, если сертификат выписан не на IP. Списки хранятся только на этом устройстве.

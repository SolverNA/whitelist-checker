# Тест белых списков (PWA для Vercel)

Статичный сайт без бэкенда. Открывается с любого телефона, проверяет из браузера
доступность ресурсов «из белого списка» и «вне белого списка», показывает вердикт,
работает офлайн после первого открытия.

## Структура

```
public/            сайт (outputDirectory)
  index.html, style.css, app.js
  sw.js            service worker: кеш оболочки, работа без интернета
  manifest.webmanifest, icons/
stamp.js           при сборке подставляет версию в sw.js
vercel.json        сборка и заголовки
```

## Деплой

1. Залейте папку в Git-репозиторий и импортируйте его в Vercel (Framework Preset: Other).
   Либо из папки проекта: `npx vercel --prod`.
2. Настройки сборки берутся из `vercel.json`: Build Command `node stamp.js`, Output Directory `public`.
3. Если сборка по какой-то причине не нужна (другой хостинг), загрузите содержимое `public/`
   как есть и меняйте `VERSION` в `public/sw.js` при каждом обновлении сайта.

## Через CDN в РФ

- Домен CDN должен отдавать сайт по HTTPS, иначе service worker не заработает.
- Не кешируйте на CDN файл `/sw.js` (или ставьте минимальный TTL), иначе обновления доедут с задержкой.
  `index.html` тоже лучше с коротким TTL.
- Пользователь должен открыть сайт хотя бы один раз, пока доступ есть. После этого страница
  работает из кеша браузера даже без интернета.
- Всегда используйте один и тот же домен: кеш, списки и история хранятся отдельно для каждого домена.

## Для пользователей

- Android/Chrome: меню → «Установить приложение». iPhone/Safari: «Поделиться» → «На экран Домой».
  Установленное приложение запускается без сети и не теряет кеш (Safari чистит данные
  сайтов, которыми не пользуются неделю, а установленные приложения не трогает).
- Списки редактируются в блоке «Списки и настройки», хранятся в localStorage устройства.
  Для переноса на другое устройство или домен: «Экспорт» → «Импорт».
- Кнопка «Поделиться» копирует/передаёт ссылку с результатом в параметре `?r=`. Формат payload:
  `{"v":2,"k":"wl|off|down|mixed","w":0..100|null,"o":0..100|null,"t":unix_ms}`.

## Что проверяется и чего нельзя

- Сайты и IP: `fetch` в режиме `no-cors` с таймаутом. «OK» значит, что DNS, TCP и TLS прошли.
- DoH: настоящий DNS-запрос по RFC 8484. Если сервер не отдаёт CORS-заголовки, проверяется только достижимость.
- DoT (порт 853) и ICMP-пинг из браузера проверить невозможно.
- IP по HTTPS: если на IP нет валидного сертификата, будет «сбой», хотя адрес доступен.
- Проверка по http для IP работает только когда страница открыта не по https.

## Локальный запуск

```
python3 -m http.server -d public 8080
```

`http://localhost:8080` считается безопасным контекстом, service worker там работает
(версия будет `__BUILD__`, это нормально для разработки).
